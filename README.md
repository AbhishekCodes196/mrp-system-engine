MRP Engine (Manufacturing Resource Planning)
A robust backend system built with Java and Spring Boot designed to optimize manufacturing operations. The application automates inventory management, calculates material requirements based on multi-level Bill of Materials (BOM) structures, and features an intuitive dashboard for real-time resource tracking and operational visibility.

MRP Engine
A high-performance Manufacturing Resource Planning system that simplifies production scheduling and inventory control.

Key Features:

Dynamic BOM Management: Handle complex, multi-level Bill of Materials and component dependencies.
Resource & Inventory Tracking: Automate material requirements planning to prevent stockouts and overstocking.
Interactive Dashboard UI: Modern, dark-themed dashboard providing high-level operational insights.
RESTful Architecture: Powered by Spring Boot for clean API integration and scalability.
